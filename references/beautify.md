# 美化已有 PPTX（beautify 路由）

> **何时读**：用户给出现成的 .pptx，要「美化 / 重排 / 换风格 / 变好看」，并且**不改内容**。**何时不读**：要改写文字、补内容、写新稿时，走正常的六项问询路径；改原稿文字走官方 pptx 技能。

## 一条命令

```bash
python scripts/beautify.py 原稿.pptx --out 新目录 [--style business-blue] [--theme light] [--compare]
```

- 原稿只读：输出目录不能是原稿所在目录，原文件逐字节不变。
- `--compare` 需要 LibreOffice + poppler，会生成前后对照图；不加时其余产物照常生成。
- 退出码 0 = 核对通过；1 = 有差异（终端逐条列出），**不得交付**。

## 流程

| 步 | 做什么 | 产物 |
|---|---|---|
| 1 解析 | `ingest_pptx.py`：逐页读标题、文本框（段落层级 / 字号 / 颜色 / 粗体）、表格、原生图表（类型 + 类别 + 系列）、图片、备注 | `source.json` |
| 2 锁定原文 | 每个段落、表格单元格、图表类别与系列名生成冻结片段（sha256） | `freeze.json` |
| 3 逐页诊断 | 4:3 画幅、字号混乱、纯红纯绿、整页长句、图表默认配色、贴边满屏图等 | `diagnosis.json` |
| 4 映射版式 | 按内容结构挑候选版式，再由 `lib_layout_pick` 按风格偏好 + 节奏规则选一个 | `plan.json` |
| 5 重新排版 | 生成 `*.beautified.model.json`（`contentLocked: true`），渲染 HTML 与 PPTX | `.html` `.pptx` |
| 6 逐字核对 | 见下节；全部通过才算完成 | `verify.json` `report.md` `compare.png` |

### 映射规则（内容结构 → 版式）

| 原页特征 | 新版式 |
|---|---|
| 第 1 页最大字号文本 | 封面（其余文本作副标题 / 落款） |
| 标题为「目录 / 大纲 / 议程」 | 目录页，标题沿用原文 |
| 末页「谢谢 / Q&A / 结束」 | 结束页，不加眉标 |
| 原生图表 + 文字 | 主图 + 侧注；饼图走构成环图（不加「合计」） |
| 表格 | 对比表，表外文字作导语或注 |
| 「标签框 + 内容框」成行 | 分层架构 |
| 带序号的网格方框 | 横向步骤（手打序号改由版式绘制） |
| 每行一个数字的指标句 | 大数字墙或主 KPI |
| 「X：Y」列表 | 特性卡 / Bento / 论据三点 |
| 2–4 条短句 | 论据三点或特性卡；长句做无标题陈述卡 |
| 其余 | 要点页（无标题卡，不补「要点一」之类的字） |

## 不改字契约（核对器 `verify`）

切分只允许三种：

- **keep**：原文片段原样搬运；
- **sep**：「：」或空白分隔符变成版式分栏（标签 / 正文）；
- **ordinal**：手打序号（「1.」「一、」）改由版式绘制。

核对五项，任何一项失败即 FAIL：

1. 每个冻结片段都有切分记录；
2. 每个 keep 片段都能在对应新页里找到，PPTX 与 HTML 两端都查；
3. 每个数字都能找回（序号允许补零）；
4. 图表类别、系列名与数值和新 PPTX 的原生 chart XML 逐项一致（条形图允许自下而上的倒序）；
5. 新页上**没有多出来的字**：PPTX 形状文本与 HTML 正文（不含图表 SVG）只能有原文 + 页码等页面骨架。坐标轴刻度、由数据派生的合计与百分比算图表本体，由第 4 项单独核对。

`contentLocked` 模型里，校验器不再要求标题写成主张句，也不因文字少报低密度；这些都属于原文本身，不能改。

## 边界

- **不改字**：不润色、不补结论条、不加眉标文案、不生成 So what；原稿没有的话一个字也不加。
- **不支持的对象**（SmartArt、OLE、音视频、非满版图片）不重绘、不猜内容，全部写进 `report.md` 的「不支持对象」，注明原稿页码；图片会导出到 `media/` 供人工放回。
- **备注**会读出来，但这一版不写回新稿。
- 动画、切换和母版装饰一律不迁移。
- 只做排版：页序与原稿一一对应；放不下时按求解器规则拆页，拆出的页在 `pageMap` 里仍指回原页。

## 测试

`python tests/beautify/test_beautify.py`：三份自造的朴素样例（`tests/beautify/samples/`，由 `make_samples.py` 确定性生成：课件 / 经营汇报 / 方案）全部核对差异为 0，原稿不变，产物通过 `validate_pptx` / `validate_report` / `check_rhythm` 三道 strict 校验；另有负例，模型里改一个字或一个图表数值都必须被拦住。CI（`ci_skill_gates.sh --with-pptx`）硬门禁。
