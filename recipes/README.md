# 路线食谱（recipes）

SKILL.md 判定路线后，只读对应的一份食谱，其他食谱不读。每份食谱写清四件事：什么时候用、输入、保留什么、产出。

| 路线 | 文件 | 一句话 |
|---|---|---|
| 从零生成 | `generate.md` | 有材料、要一份正式演示文稿或报告，走完整问询与幽灵稿 |
| 快速出稿 | `fast.md` | 用户说「快速模式 / 直接生成 / 一键出稿」，跳过问询直接出 |
| 美化已有 PPTX | `beautify.md` | 给了 .pptx，要换风格重排，原文一字不改 |
| 套用参考模板 | `template.md` | 给了参考 PPTX 或品牌规范，要按它的配色与字体出稿 |
| 架构图 | `architecture.md` | 要分层图、拓扑、流程、泳道，1–8 页、图解优先 |
