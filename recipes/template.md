# 食谱 · 套用参考模板

**什么时候用**：用户给了公司模板、参考 PPTX 或品牌规范，希望新稿「用这个配色和字体」。

| 输入 | 保留什么 | 产出 |
|---|---|---|
| 参考 .pptx（只读）+ 本次材料 | 参考文件只取主题色和字体，不复制其版式、图片或文字 | `template.json`（品牌色、字体、最接近的内置风格）+ 按「从零生成」交付的 HTML / PPTX |

## 步骤

1. 提取：`python3 scripts/extract_template.py 参考.pptx --out template.json`
   输出品牌色（dk1/lt1/accent1–6）、标题与正文字体、明暗倾向，以及按色差排序的最接近 3 套内置风格。
2. 选型：取 `suggest.style` 与 `suggest.theme` 作为六项问询里风格与亮暗的推荐值。ΔE ≤ 10 视为同色系；ΔE > 10 要在问询时直说「最接近的是某某风格，与贵司主色有差异」。
3. 其余按 `generate.md` 走（Gate 0 可以直接换成这份推荐）。
4. 交付说明里写明：采用的内置风格、品牌主色与它的色差。

本技能不做自定义品牌引擎：交付始终是 12 套风格之一，这样 HTML 与 PPTX 的配色、对比度和图表色板都经过校验。
