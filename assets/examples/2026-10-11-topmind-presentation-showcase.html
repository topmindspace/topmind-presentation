市面 PPT 技能很多，为何还要 topmind-presentation

正式商务演示

  • 不是花哨 gadget。为演示报告与上台汇报而生——直观、大气、可编辑
  • 一屏一主张。标题即行动句，少装饰堆砌

HTML + PPT 双交付

  • HTML 日常上台。单文件可翻页，等同幻灯片
  • PPTX 按需导出。版式保真、可继续编辑

MD3 式克制

  • 密度合适。文字/图形/形状/颜色克制
  • 无 AI chrome。结论条 tonal 满铺，禁左侧装饰轨
产出即上台：同源模型保证 HTML 与 PPTX 一致，图表带数据可核对。

安装与分发：一条命令装好，升级不降级

仓库即技能

  • 仓库即技能。SKILL.md、脚本与素材同仓
  • 一条命令安装。有新版直接覆盖，不备份

三条安装规则

  • 不悄悄降级。已装更新版时报错，--force 才降
  • 同名目录自动替换。同一技能直接替换；无关目录需 --force

只发运行所需

  • files 白名单。不含落地页、截图和评测集
  • 同 tag 发版。GitHub Release 与 npm 版本号一致
版本号与 tag 一致，装哪一版就用哪一版；升级、拒绝降级、同名替换三条规则都有测试。

双交付：HTML 即演示，PPTX 可继续编

  • 日常 HTML 上台。单文件可翻页，等同幻灯片；亮暗与十二风格顶栏即切
  • 需要时再出 PPT。版式保真可编辑 PPTX；图表数据可标注、可核对
  • 克制的商务面。参考 MD3：合适信息密度，少装饰、一屏一主张
工艺关注点（产品强调 · 示意权重）
工艺在结构与密度，不在 gadget——正式场合演讲/汇报才是主场。

模式先定后写：A 演示 · B 研究 · C 架构

A · 演示

  • 每屏一主张。标题即行动句，非话题标签
  • 大气留白。证据充分但不堆咨询 dump

B · 研究

  • 咨询密排。Exhibit · 来源 · 结论条
  • 结论可核对。数字与口径双向对齐

C · 架构

  • 图为王。拓扑 / 泳道 / 分层
  • 少字多结构。一图说清关系
先定模式再写页——A/B/C 契约决定密度、图表与结论条用法。

HTML 与 PPTX 的分工

HTML 是阅读与演示界面，PPTX 是协作与修改格式——两者来自同一内容模型（window.REPORT_MODEL），PPTX 内全部是原生形状、文本框、表格（pictures=0），可在 PowerPoint / WPS 中继续编辑；带数据的图表为原生数据图表（chart 对象 + 内嵌 Excel，双击即可"编辑数据"）；口径、来源与结论条自动写入演讲者备注，不占版面。

怎么获得 PPTX

页面预览（P）· 所见即所得

点 header 的「预览」按钮查看 WYSIWYG 页序列——预览与智能体精导使用同一序列化引擎，看到的即交付所得。页面不直接导出文件（浏览器端达不到 strict 质量硬门禁）。

智能体精导 · 唯一交付通道

复制下方提示词回到 AI 对话，由本地智能体执行 extract_model.py → build_pptx.js --model → validate_pptx.py --strict，0 错误 0 警告才交付（含模型往返保真检查）。

命令序列（智能体精导）

python scripts/extract_model.py 报告.html
node scripts/build_pptx.js 报告.pptx --model=报告.model.json
python scripts/validate_pptx.py 报告.pptx --strict --model=报告.model.json

可复制提示词（交给 AI 生成 PPTX）
