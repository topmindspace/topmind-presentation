# 食谱 · 快速出稿（Fast Mode）

**什么时候用**：用户明确说「快速模式 / fast / 直接生成 / 一键出稿 / 少问一句」。

| 输入 | 保留什么 | 产出 |
|---|---|---|
| 材料或一句话主题 | 材料里的数字与结论；没有数据就不编数据 | `报告.html`（默认只出 HTML）；用户要 PPTX 才加 `报告.pptx` |

## 默认值（一行宣布「Fast 选用：…」后直接做）

- 模式：默认 B 研究型；路演、汇报、发布、演讲、融资 → A 演示；架构、拓扑 → C。
- 风格：A → business-blue（清新蓝白）· B → mckinsey · C → graphite-dark。主题浅色（graphite-dark 用深色）。
- 篇幅：A 10 页 / B 12 页 / C 6 页。

## 步骤

1. 跳过 Gate 0 与六项问询，在回复里说明已跳过参考图。
2. 写最小大纲（章名 + 每页主张标题），不等确认。
3. 模型单写 → `render_from_model.py` 渲染 → `validate_report.py --strict` 0/0。
4. `quality_gate.py --deliver` 出交付说明。质量要求和标准路线一样：不截断、图表不重样、不留空页。

快路径省的是问询，不省校验。
