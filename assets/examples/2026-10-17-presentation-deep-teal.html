HTML 与 PPTX 的分工

HTML 是阅读与演示界面，PPTX 是协作与修改格式——两者来自同一内容模型（window.REPORT_MODEL），PPTX 内全部是原生形状、文本框、表格（pictures=0），可在 PowerPoint / WPS 中继续编辑；带数据的图表为原生数据图表（chart 对象 + 内嵌 Excel，双击即可"编辑数据"）；口径、来源与结论条自动写入演讲者备注，不占版面。

怎么获得 PPTX

页面预览（P）· 所见即所得

点 header 的「预览」按钮查看 WYSIWYG 页序列——预览与智能体精导使用同一序列化引擎，看到的即交付所得。页面不直接导出文件（浏览器端达不到 strict 质量硬门禁）。

智能体精导 · 唯一交付通道

复制下方提示词回到 AI 对话，由本地智能体执行 extract_model.py → build_pptx.js --model → validate_pptx.py --strict，0 错误 0 警告才交付（含模型往返保真检查）。

python scripts/extract_model.py 报告.html
node scripts/build_pptx.js 报告.pptx --model=报告.model.json
